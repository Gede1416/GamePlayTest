# FairyGUI 独立组件测试用例

这是一组可手动运行的交互测试场景，不是 Unity Test Runner 自动化测试。
打开本目录任意 `.unity` 场景并 Play；一次运行一个，切换前停止播放。不需要添加 Build Settings。
每个场景共用 FairyGUIComponentCase，caseIndex 已在场景中配置。
使用现有 Basics 发布包，以及随附的官方 TreeView、Transition 发布包；无需先打开 FairyGUI 编辑器发布。

| 场景 | 操作 | 预期结果 |
|---|---|---|
| 01_VirtualList | 滚动最左侧列表到底，再回顶部，点击条目；组件右键“验证虚拟列表复用” | 显示物品 0001～1000，选择输出日志；自检报告 1000 条数据、少于 100 个可视条目实例 |
| 02_Tree | 展开右侧分类 1～3，再折叠；点击叶子 | 每类 10 个条目，折叠隐藏子节点；点击日志对应所选节点。左侧保留官方静态树作为对照 |
| 03_PagingAndSnap | 横向拖动右上方 Single row 列表，再横向拖动左侧第二列 Flow vertical 列表 | 前者松手吸附条目，后者按页停靠；其余列表保留普通滚动供对照 |
| 04_Window | 点击 WindowA，拖动标题栏并关闭；点击 WindowB，尝试点击窗口外，再关闭 | 普通窗口可拖动关闭；模态窗口阻止底层点击；重复打开不会叠加同一窗口 |
| 05_Controller | 点击界面上的状态切换按钮，反复切换 | 对象位置、大小、颜色、可见性随控制器状态变化；c1 切换输出页码日志 |
| 06_Transition | 观察 BOSS 动效，等待多次循环，然后停止播放 | t0 动效循环播放；停止播放后不遗留界面和动效对象 |
| 07_DragDrop | 拖动 A；将 B 图标拖到 C；拖动 D 到边框外；将 B 拖到空白处 | A 自由移动；C 接收图标并输出成功日志；D 受边界限制；无效落点不修改 C |
| 08_RichTextAndInput | 点击富文本链接；在输入框输入中文和英文，点 Get Input | 链接输出目标日志；输入内容原样显示到结果文字；颜色、图文样式保持正常 |
| 09_Slider | 拖动各滑块到两端，再拖到中间 | 值在资源设定范围内变化，Console 输出当前滑块名和值 |
| 10_ProgressBar | 等待至少 6 秒 | 多种进度条同步从 0 增加到 100 后循环；数值与填充方向符合各自样式 |

通用回归：每个场景停止、重新 Play 两次，确认 Console 没有异常，窗口没有残留。

## 资源与编辑

UI 源工程仍是 `../UIProject~/Workflow.fairy`。对应包为 Basics、TreeView、Transition。
Basics/Main 仍是原综合控件实例；这些测试使用其他 Demo_* 组件，不会替换它。
源工程资源名称与代码绑定名称需要保持一致。修改对应包后发布到 `../Resources/UI`。
图形及控件沿用官方 MIT 示例，不添加新的 UI 框架或代码生成工具。

## 验证状态

脚本已通过引用 Unity/FairyGUI 程序集的 C# 编译检查；场景索引与资源清单由 validate.ps1 检查。
